# 下移纪律（把「判断」交给脚本时守什么）

> 由维护口径（2026-10-17）定调，落成可执行的检查表。**改动本技能前读本文**；它不是客户可见内容，不进任何交付页。

## 一、三类东西，三种处理

| 类别 | 特征 | 处理 | 例子 |
|---|---|---|---|
| **机械判断** | 可枚举、有唯一正确答案 | **必须下移**，全库只有一处实现 | 票种、时间窗口、换乘时长、总价、日期与节假日、JSON 骨架、网址可达性、门禁校验 |
| **半下移** | 要读客户意图，但结论只有几种 | 脚本给**候选集 + 判据**，模型只做一次选择 | 是否要求往返、是否对方案不满意、是否已有出行方案（`flow.js criteria`） |
| **不下移** | 取舍与沟通 | **留在模型**，脚本只给素材 | "这 4 个方案里推荐哪个、为什么"、"预算紧但不赶时间怎么办"、"拒绝境外时怎么把话说到位" |

**为什么第三类不能脚本化**：满意度就长在这些地方。把取舍做成模板回复，技能会变成冷冰冰的自动售货机——模板一旦不匹配客户语境，比没有更糟。

## 二、四条纪律（改动前逐条对）

1. **一个规则只能有一个真源。**
   `spots` 的形状闸门（`lib/validate.js`）与质量评审（`spot_link.js`）曾经各判各的：闸门按 URL 形状一刀切，评审按内容要点打分。处置：**闸门只保留反爬/黑名单**，"频道·栏目首页""政府日期稿件页"两条改为**条件生效——评审判 A/B 就放行、判 weak/F 才拦**（`REVIEW_EXEMPT` + `reviewGrade()`）。
   要么在脚本里，要么正文写一句判据 + `--help` 指针。**两处都写必然漂移**（本项目已漂过一次：`SKILL.md` 儿童票价表 vs `plan.js` 的 `childFactor`；政务页口径 vs 实际校验）。
   - 现状：节假日 = `scripts/lib/holiday.js`（`dateinfo.js` 与 `hours_check.js` 共用）；窗口/换乘/归位/总价 = `scripts/plan.js`；骨架 = 四个 `emit`；网址 = `spot_link.js` + `spots_urlcheck.js`；门禁 = `gate.js`（内含 `spots_check` / `make_html --check` / `reply_check`）。
2. **门禁必须阻断，不能只提醒。**
   曾经的 `spots_check --need` 恒 `exit 0` 就是"假门禁"：白付一次调用，还给了"已经检查过"的错觉。现在它已明确降级为**决策提示**（只回答"要不要派景点预研"，文档与 `--help` 都不再称它为门禁）。新增检查一律 `exit ≠ 0`，除非明确写下"这是提醒、不阻断"并说明理由（例：`reply_check` 的 R3「不复述页面」是 WARN，因为它是文风问题）。
3. **脚本的输出必须是给模型看的摘要，不是原始数据倾倒。**
   `12306.js` 默认全量 JSON（数百 KB）→ `--brief`（每车次一行，含全部席别）→ `--digest`（5 列：车次 / 发到时 / 历时 / 最便宜席别票价 / 余票）。**只想看有哪些车 → `--digest`；要喂 `plan.js` → `--brief`（它按 brief 行解析）**。
4. **脚本要稳、要幂等、不要把状态写进技能目录。**
   `data/spots-links.json` 是例外：它是**评审结论数据集**（可提交、跨机器复用），不是会话状态 → 留在 `data/`；代价是拖久了会过期，所以 `spots_check` 的 B8 在到期前 **15 天**打 `WARN` 提醒跑 `spot_link.js refresh`（提醒不阻断，到期才 FAIL）。**会话状态**（重生成计数、站表、正负缓存、航班）一律在 `%TEMP%\travel-cache\`。
   跨会话残留的配额与缓存，会在客户最需要"重出一版"时把路堵死——这是本技能曾经最尖锐的一处悬崖（改第 2 次主意被拒）。现状：重生成计数、12306 站表/正负缓存、航班缓存全在 `%TEMP%\travel-cache\`（`RAIL_CACHE_DIR` / `FLIGHT_CACHE_DIR` 可覆盖）；计数前 2 次正常、第 3–5 次只 WARN、**第 6 次 REFUSE**（`node scripts/make_html.js --reset-runs <out.html>` 复位）。

## 三、自查方法（改动后跑）

```bash
# 1) 真源是否唯一：同一数值/判据在几处出现
grep -rn "8:00–10:00\|≥ 30 分钟\|45 分钟\|5～10 个" SKILL.md references/ scripts/ | wc -l
# 2) 假门禁：文档里承诺"拦下"的检查，脚本是否真非 0 退出
grep -rn "exit 0\|process.exit(0)" scripts/*.js
# 3) 状态文件是否落到技能目录
ls scripts/.??* 2>/dev/null; grep -rn "__dirname" scripts/*.js | grep -i "cache\|runs"
# 4) 摘要 vs 倾倒：脚本有没有"一行一条"的摘要模式
node scripts/12306.js tickets 广州南 武汉 2026-10-19 --digest | head -3
```

## 四、判断"该不该下移"的一句话

**能用"是/否/哪一个"说完的，交给脚本；需要说"为什么"和"怎么办"的，留给自己。**
