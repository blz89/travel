# 席别与时间窗口规则（完整决策树）

## 时间窗口规则（加入时间考量，以有票为主）

- **用户未指定出发时间（填"否"）**：默认出发窗口为 **8:00–10:00**。
- **用户指定时间 T**：优先窗口 **T ～ T+1 小时**（尽量在该时间段 1 小时内出发）；**放宽窗口为 T ～ T+2 小时**（最迟晚 2 小时）。
- **窗口含义**：针对"从出发地出发的时刻"——铁路取列车 **发车时间**；飞机取**离开出发地（去机场）的时刻**，且**必须在航班起飞前 1.5 小时到达机场**（安检、值机、登机缓冲），即：
  `从出发地出发的时刻 = 航班起飞时间 − 1.5 小时 − 去机场接驳耗时`
  方案中必须标注这个换算（含所用接驳方式与耗时）。**去机场接驳耗时**：本地有机场 = 直达地铁/直达动车·城际/直达大巴的耗时；**本地无机场 = 铁路到市区站的耗时 + 市区站→机场直达线的耗时**（见「空中方案的成立条件与定位」）。
- **筛选顺序**（所有方案通用）：先在**优先窗口**内找车次/航班；没有或余票不足 → 放宽到 **2 小时窗口**（放宽是为提高有票概率，**有票优先于时间精确**）；仍不足 → 如实说明，给出**窗口外最近的可选班次**（标注"不在指定窗口内"）。
- **铁路中转方案**：第一段列车的发车时间必须在窗口内；第二段的发车时间必须满足「换乘时间规则」的**到站后余量**门槛（**一律 ≥30 分合格 / 20–29 分标红警告 / <20 分不可行；异站须给 `transferMin` 或补接驳腿**），否则该中转不可行。（**空中的转机/中转另见`references/air-fallback.md`**——平台联程中转不做时间校验）

## 人数与余票规则

- 12306 余票字段（`seats`）的取值含义：**数字**=剩余张数；**"有"**=充足（按充足处理）；**"无"**=无票；**空/缺**=该席别不售或当日无票。
- **校验**：对每个推荐车次/席别，剩余张数（数字）**小于出发人数** → 标注"余票不足（剩 N 张）"，再按下面基准条处理（**能拼票就拼票，补不齐才弃该车次**）；"有" → 标注"满足 X 人"。
- **校验基准 = 方案的「主选席别」**（定义见「席别规则」）：**主选席别无票的车次不得作为该方案——唯一例外 =「无票兜底」（买长乘短 / 补票，见 SKILL.md 该节）**；**有余票但不足 X 人时，按「席别规则 → 拼票」处理**（补得齐就拼票并写明各买几张，补不齐则弃该车次）。
- 所有方案必须标注：该班次**是否满足 X 人**（满足 / 余票 N 张不足 / 无票）。
- 空中：web_search 结果通常不含剩余座位数，统一标注"座位数以购票时为准"；人数较多时提示尽早购票。

## 席别规则（铁路席别 · 空中舱位）

**铁路方案必须写明席别（硬性）**：只写"高铁 G878 ¥250"不合格，必须写"高铁 G878 **二等座** ¥250"。每个铁路方案都要定一个**主选席别**，方案费用按**该席别票价**计算。

- **主选席别按车型定（硬性）**：
  - **高铁 / 城际 / 动车（G / C / D）→ 默认「二等座」**，**且封顶一等座**（见下条「G/C/D 席别上限」）。**夜行动车（动卧）同样按动车处理、优先二等座**——不因为过夜就改推卧铺。
  - **普速（K / T / Z / 纯数字）→ 按「普速席别顺序」取第一个够 X 人的席别**（见下条）。
  - 用户明确指定席别（"要硬卧""坐一等座"）时从其指定。
- **G / C / D 席别上限 = 一等座（硬性）**：**默认只到一等座，商务座、特等座默认不列**——默认不作主选席别、不进方案与文档、不参与比价。**默认不列、不参与比价；客户点名要时按其指定办**（此时"上限 = 一等座"不适用）。
- **G / C / D 的席别与无票顺序（硬性，按序执行）**：
  1. **二等座够 X 人** → 主选**二等座**（默认路径）；
  2. **二等座无票、一等座有票** → 主选**一等座**（这是唯一允许的升级，且仅此一档）；**一等座不够 X 人时已无更高档可补 → 该车次不作为候选**（见下条「拼票」）；
  3. **二等座有余票但不够 X 人** → 差额用**一等座**补（补法见下条「拼票」）；
  4. **二等座、一等座都无票** → 走「无票」路径（见`references/no-ticket-fallback.md`）；
  5. 以上都不成立 → **该车次不作为候选**。
- **普速席别顺序（硬性）**：普速有**硬座 / 硬卧 / 软卧**三种座卧席别，按顺序取**第一个有余票**的席别作主选（够 X 人则直接用；不足 X 人按下面的「拼票」处理）：
  - **普通普速**（未跨天到达、历时 < 12 小时）→ 按**票价由低到高**（通常**硬座** → 硬卧 → 软卧）；
  - **长途普速**（**跨天到达** **或** **历时 ≥ 12 小时**，**不管是否过夜**）→ **硬卧 → 软卧 → 硬座**（坐这么久硬座不现实，故排最后；不是硬卧时如实说明"硬卧已无票 / 该车次无硬卧"）；
  - **跨天到达以 `--brief` 的 `(+1天)` 标记 / JSON 的 `arrives_next_day` 为准**（不要靠肉眼比对钟点去猜）；
  - 顺序里**没有一个够 X 人** → 差额用**票价高于主选席别的可买席别**补（补法见下条「拼票」）；
  - **G/C/D 不适用本条**（夜行动车按动车、优先二等座）。
- **拼票（主选席别有余票但不够 X 人时；G/C/D 与普速共用）**：**差额用「票价更高的可买席别」补**——G/C/D = **一等座**；普速 = 按**票价高于主选席别**的档；**≤45 分钟的短途还可用无座补**（见下）。**补得齐才给**：
  - 例：3 人、该车次二等座剩 1 张、一等座剩 5 张 → **1 人二等座 + 2 人一等座**；写明各买几张与各自单价。
  - **补不齐 → 该车次不作为候选**。"补不齐"包括：差额买不到票，或主选席别**已是该车型可列的最高档**（G/C/D 主选已是一等座、长途普速主选是软卧时即属此类）。**不得**为留住车次去列商务座/特等座。
  - **短途可用无座补差额（≤45 分钟）**：该段乘车历时 **≤ 45 分钟**时，差额可用**无座**补，即"**主选席别 + 无座**"（受「无座票规则」约束）；**历时 > 45 分钟一律不得用无座补差额**。
  - **价格口径**：拼票方案的人均价 = **各人票价之和 ÷ X 人**，用该人均价参与三段归位。
  - **是否值得推荐（硬性评判）**：拼票**会抬高人均价**，所以**必须和同 OD 的其他方案一起参与三段归位**——**只有它仍进得了"最省钱 / 最快 / 额外"时才作为正式方案展示**；**归不进去就不列为方案**，只在聊天回复里一句话兜底说明（如"该车次二等座只剩 2 张，另 3 人可买一等座，人均 ¥XXX，但不比其他方案划算，故未列为方案"）。
- **「最省钱方案」的价格标准**：取**主选席别票价**（G/C/D = **二等座价**，二等座无票时为**一等座价**；普速 = 按「普速席别顺序」选中的那个席别的价）；**拼票方案取「各人票价之和 ÷ X 人」的人均价**；全部候选必须按**同一口径**（席别价 / 拼票人均价）比价，不得用贵席别去抬高或压低任何一个方案的价格口径。
- **无座票**：见下面「无座票规则」小节。
- **中转换乘 / 多段方案**：**逐段各自**按上面各条定主选席别，总费用 = 各段该席别票价之和；不得用某一段的贵席别去凑另一段的低价。

### 无座票规则（45 分钟门槛；只有补票才是例外）

**无座票不得"直接买"**。它只在下面两种情形下才允许出现，且必须在方案里能一眼区分：

- **乘车历时 ≤ 45 分钟 → 无座可以推荐**（短途站一会儿可接受）：可作**主选席别**；作主选席别时**票价按同车次硬座 / 二等座价计**（无座与硬座·二等座同价，以出票页为准）。
- **乘车历时 > 45 分钟 → 一律不得推荐无座**：**不作为主选席别、不出现在任何方案里**。
  - **唯一例外 = 补票策略**（见`references/no-ticket-fallback.md`）：**先买一张能上车的短途票、上车后再补到目的站**，补票那一段才是无座。
  - **补票 ≠ 买无座票**：两者的区分方式与标注要求见`references/no-ticket-fallback.md`。
- **优先级（裁决）**：历时 ≤ 45 分钟、且该车次**我们考虑的席别已无票、只有无座有余票**时，**直接用无座作主选席别**——**优先于「买长乘短」与「补票」**（有票就直接买，不为省这点钱绕路）。只有**无座也没有余票**时，才走无票路径。
- 注意此处判的是**该段乘车历时**（`--brief` 里的历时字段），不是含接驳的总耗时。
